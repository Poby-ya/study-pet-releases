# 공부 친구 (Mac)

공부를 시작하면 화면 구석에 작은 교실이 뜨고, 책상에 앉은 학생 펫이 같이 공부해 주는 앱입니다.
친구들과 같은 방에 들어가 옆자리에 앉고, 서로 깨워 줄 수 있습니다.

## 설치 (업데이트도 똑같이)

1. ⌘+스페이스를 누르고 "터미널"을 쳐서 엽니다.
2. 아래 한 줄을 통째로 복사해 붙여 넣고 Enter를 누릅니다.

```
/bin/bash -c "$(curl -fsSL https://github.com/Poby-ya/study-pet-releases/releases/latest/download/install-mac.sh)"
```

3. 화면 맨 위 오른쪽 메뉴 막대에 펫 얼굴이 생기면 끝입니다.

- macOS 13(Ventura) 이상, Apple 칩과 Intel Mac 모두 됩니다.
- 앱은 홈 폴더의 `응용 프로그램`(`~/Applications/StudyPet.app`)에 들어갑니다.

## 쓰는 법

- `⌃ control + ⌥ option + S`: 공부 시작 / 일시정지
- `⌃ control + ⌥ option + X`: 그만하기
- 펫 얼굴(메뉴 막대) → **친구와 공부하기 ▸ 초대 코드 넣기…**: 받은 초대 코드를 붙여 넣고 닉네임·이름·추천인을 적으면, 방장이 승인한 뒤 방에 들어갑니다.

이 저장소에는 배포 파일만 있습니다. Windows 판은 방장에게 받으세요.
